1 Tong quan du an

1.1. Du an nay lam gi?

Chuong trinh nhan dien cam xuc tren khuon mat nguoi theo thoi gian thuc. Mo webcam len, chuong trinh se:

  1. Phat hien khuon mat trong khung hinh (Haar Cascade).
  2. Cat tung khuon mat ra, xu ly CLAHE can bang sang.
  3. Dua qua mo hinh AI (EfficientNet da duoc huan luyen san) de du doan cam xuc.
  4. Hien thi ket qua ngay tren man hinh: khung mau + ten cam xuc + do tin cay.

Ngoai webcam, con co che do anh tinh, file video, fine-tune model, va danh gia ket qua.

1.2. Kien truc tong the

Toan bo he thong nam trong 1 file duy nhat: main.py (~400 dong), chia lam 4 phan:

main.py
│
├── Phan 1: Constants + Imports (~15 dong)
│   - Dinh nghia 6 emotion labels
│   - Mau sac hien thi

├── Phan 2: EmotionEngine class (~70 dong)
│   - Khoi tao HSEmotion recognizer

│   - Temporal Smoothing + Adaptive Threshold

│   - report() — ve bieu do pie + timeline
│

Tai sao chi can 1 file? Cac file nhu capture.py, image_predictor.py, evaluator.py truoc day la cac class nho, moi class chi co 1-2 method public. Gom vao 1 file giup giam so luong file tu 8 xuong 1, de quan ly hon, van giu nguyen chuc nang.

4 Giai thich main.py

Toan bo code nam trong main.py. Duoi day la giai thich tung thanh phan chinh.

4.1 class EmotionEngine

Day la "trai tim" cua he thong. Chua toan bo logic phat hien mat va nhan dien cam xuc.

__init__(model_name, weights_path)

Khi tao EmotionEngine, 4 viec xay ra:

  1. Khoi tao HSEmotionRecognizer (tai model EfficientNet ~25MB).
  2. Tai Haar Cascade phat hien khuon mat.
  3. Load fine-tuned weights neu co.
  4. Tao CLAHE de can bang anh sang.

Dong quan trong:

self.er = HSEmotionRecognizer(model_name=model_name)
self.fc = cv2.CascadeClassifier(FACE_CASCADE)
self.clahe = cv2.createCLAHE(clipLimit=2.0, tileGridSize=(8,8))
detect(frame) / predict(face_img) / process(frame)

detect(): Chuyen anh sang xam → Haar Cascade → tra ve list [(x,y,w,h)].

predict(): Chap nhan 1 anh mat da crop:

  • BGR → Gray → CLAHE → RGB (tien xu ly)
  • Goi HSEmotion.predict_emotions() → 8 xac suat
  • Neu model goc: chon 6/8 xac suat tuong ung [0,2,4,5,6,7]
  • Neu fine-tuned: lay 6 xac suat dau tien

process(): Ham tong hop:

  • Goi detect() → loc mat ≥48px
  • Voi moi mat: predict() → Temporal Smoothing → Adaptive Threshold
  • Tra ve list: [{'bbox','emotion','confidence','probs'}]
Temporal Smoothing (co che)

Moi khuon mat co 1 buffer rieng (deque maxlen=10). Them ket qua moi vao buffer, tinh trung binh 10 frame gan nhat. Giam nhap nhay do nhieu anh tam thoi.

if k not in self.bufs: self.bufs[k] = deque(maxlen=10)
self.bufs[k].append(scores)
avg = np.mean(self.bufs[k], axis=0)

Key cua buffer duoc tinh tu toa do tam, luong tu hoa 60px → neu mat rung <60px, key khong doi → buffer khong bi reset.

Adaptive Threshold (nguong rieng)

Moi emotion co nguong rieng. Neu xac suat cao nhat < nguong → mac dinh Neutral:

nguong = {
    'Happiness': 0.50,  'Sadness': 0.30,  'Surprise': 0.35,
    'Anger': 0.40,      'Neutral': 0.35
}

4.2 class SessionStats

Ghi nhan lich su cam xuc trong 1 phien webcam/video va tao bao cao truc quan (pie chart + timeline) khi ket thuc.

record(t, results) / report()

record(): Append-only, O(1) — khong anh huong FPS. Chi lay face dau tien lam primary.

report(): Ve pie chart phan bo + timeline scatter plot → luu vao reports/emotion_report.png.

4.3 load_model(model_name, num_classes)

Ham tinh (static) dung de tai model EfficientNet tu cache cua HSEmotion, sua loi tuong thich key cua timm, va tra ve model PyTorch san sang.

load_model() — chi tiet
  1. Lay duong dan file .pt tu get_model_path(model_name)
  2. Load checkpoint bang torch.load()
  3. Rename key classifier.0.weight → classifier.weight (tuong thich timm moi)
  4. Chon architecture: B0 hoac B2
  5. Tao model bang timm, load state_dict (bo qua classifier neu shape khong khop)

4.4 do_finetune(dataset_dir, ...)

Fine-tune model tren dataset tu thu thap. Chien luoc: dong bang backbone, chi mo 2 blocks cuoi + classifier.

do_finetune() — cac buoc
  1. Load model EfficientNet voi 6 output classes
  2. Freeze toan bo tham so, chi unfreeze 2 blocks cuoi + classifier
  3. Doc dataset tu thu muc, map ten folder → index emotion
  4. Chia 70% train / 15% val / 15% test (seed=42)
  5. Training loop:
    • Forward → CrossEntropyLoss → Backward → Adam optimizer
    • Validation sau moi epoch (khong backward)
    • Luu checkpoint neu val_acc > best
Tai sao dong bang backbone? Dataset chi ~366 anh. Neu mo toan bo 5.3M tham so → overfit ngay. Chi mo ~0.5M tham so (2 blocks cuoi) thi 366 anh la vua du.

4.5 do_evaluate(model_name, weights_path, ...)

So sanh model goc (8 class) vs model fine-tuned (6 class) tren test set. In accuracy, precision, recall, F1. Ve confusion matrix + training curve.

do_evaluate() — chi tiet
  1. Load 2 models: base (8 classes) + fine-tuned (6 classes)
  2. Chay ca 2 tren test set, luu y mapping index:
    • Base: output[:, [0,2,4,5,6,7]] (bo Contempt index 1, Fear index 3)
    • Fine-tuned: output[:, :6] (6 classes)
  3. In classification report (precision, recall, F1)
  4. Ve confusion matrix heatmap
  5. Ve training curve (loss + accuracy) neu co history

5 Giai thich khai niem chuyen mon

Haar Cascade
Thuat toan phat hien vat the co dien (Viola-Jones 2001). Quet cua so nho qua anh, so sanh tong pixel giua 2 vung. Neu du nhieu dac trung khop → do la khuon mat. Uu: rat nhanh, chay CPU. Nhuoc: kem voi mat nghieng, thieu sang.
BGR vs RGB
OpenCV doc anh theo BGR (Blue-Green-Red), khac RGB thong thuong. Can chuyen doi khi dung matplotlib.
EfficientNet
Kien truc neural network do Google phat trien (2019). Can bang 3 chieu: do sau, do rong, do phan giai → chinh xac toi da voi it tham so nhat. Code dung phien ban B0 (nhe nhat).
Softmax & Argmax
Softmax: Bien mang so thanh xac suat (tong = 1). Argmax: Lay chi so phan tu lon nhat. VD: argmax([0.02, 0.85, 0.03]) = 1.
Temporal Smoothing
Dung deque luu 10 ket qua gan nhat, tinh trung binh → giam nhieu, cam xuc thay doi tu tu.
CLAHE
Can bang sang cuc bo. Chia anh thanh o 8x8, can bang tung o rieng, co gioi han tuong phan → noi chi tiet, tranh nhieu.
CrossEntropyLoss
Loss = -log(p) voi p la xac suat model du doan cho lop dung. Model doan dung 95% → loss~0.05. Sai → loss cao.
Fine-tuning (Huan luyen them)
Giu kien thuc tu 450k anh (dong bang backbone), chi day them dac diem rieng tu dataset nho (mo 2 blocks cuoi + classifier). Giong nhu dau bep da gioi, chi can chinh theo khau vi gia dinh.
Learning Rate & Epoch
Epoch = 1 lan quet het dataset. Learning Rate = kich thuoc buoc cap nhat trong so. Mac dinh 1e-4 phu hop fine-tune.
Overfitting (Qua khop)
Model "hoc thuoc" du lieu train, khong tong quat hoa duoc. Dau hieu: train acc cao, val acc thap. Code chong bang: freeze backbone, validation moi epoch, chi luu best model.
Confusion Matrix
Bang N×N: hang = nhan that, cot = nhan du doan. Duong cheo = dung, ngoai = sai. Giup biet lop nao model yeu.
Precision, Recall, F1
Precision = doan dung / tong so lan doan. Recall = tim duoc / tong so that. F1 = trung binh dieu hoa cua Precision va Recall.
GPU vs CPU
Code tu dong chon device. GPU (CUDA) nhanh hon CPU 10-50 lan. Khong co GPU thi van chay duoc tren CPU.

6 Cau hoi bao ve

1 Tai sao dung HSEmotion ma khong tu train tu dau?▼
Training EfficientNet tu dau can hang tram nghin anh va nhieu ngay tren GPU manh. HSEmotion da train san tren AffectNet (450,000 anh). Minh chi fine-tune tren dataset nho (366 anh) — vua nhanh (vai phut), vua tan dung duoc kien thuc tu tap du lieu lon (transfer learning).
2 Haar Cascade — uu nhuoc diem? Co the thay bang gi?▼
Haar Cascade nhanh (real-time tren CPU), nhung kem voi mat nghieng, bi che, thieu sang. Co the thay bang MTCNN (chinh xac hon, cham hon) hoac YOLOv8-face (can GPU).
3 Temporal Smoothing hoat dong the nao?▼
Moi khuon mat co buffer rieng (deque maxlen=10 frame). Them ket qua moi vao buffer, ket qua cuoi = trung binh 10 frame. Giup tranh nhay loan emotion do anh bi nhieu hoac mat mo tam thoi. Key buffer duoc tinh tu tam mat, luong tu hoa 60px de neu chi rung nhe, key khong bi reset.
4 Tai sao moi emotion co nguong rieng?▼
Happiness thuong duoc du doan voi do tin cay cao (≥80%), nguong 0.50 an toan. Sadness va Surprise de bi nham, diem thap hon → ha nguong xuong 0.30-0.35 de khong bo sot. Neu khong dat nguong → tra ve Neutral (an toan nhat).
5 Dataset gom nhung emotion nao? So luong?▼
6 lop: Anger, Disgust, Happiness, Neutral, Sadness, Surprise. Moi lop 61 anh → tong 366 anh. Anh duoc lay tu Kaggle FER2013 + AffectNet subset.
6 Qua trinh fine-tune chia du lieu the nao?▼
Chia 70% train (~258 anh), 15% val (~54 anh), 15% test (~54 anh). Chia ngau nhien voi seed co dinh 42 de ket qua tai lap duoc.
7 Tai sao dong bang backbone, chi mo 2 blocks cuoi?▼
Backbone da hoc dac trung tong quat tu 450k anh. Dataset rieng qua nho (258 anh train) — neu mo toan bo se overfit ngay. Chi mo 2 blocks cuoi + classifier (~0.5M tham so) de tinh chinh rieng cho dataset cua minh.
8 Dau hieu overfit? Code xu ly gi de chong?▼
Dau hieu: train acc cao nhung val acc thap. Code chong bang: (1) dong bang backbone, (2) validation moi epoch, (3) chi luu model khi val accuracy tot nhat (best model), khong luu model cuoi cung.
9 Confusion matrix cho biet gi?▼
CM la bang N×N: hang = nhan that, cot = nhan du doan. Duong cheo = dung, ngoai = sai. Giup biet lop nao model yeu nhat, va no bi nham voi lop nao. VD: Fear va Surprise hay nham nhau vi deu co mat mo to, mieng ha.
10 Muc dich cua CLAHE?▼
CLAHE can bang sang cuc bo. Webcam trong phong hoc thuong bi anh sang khong deu — mot ben sang, mot ben toi. CLAHE chia anh thanh o 8x8, can bang tung o rieng → ca khuon mat deu ro net, model nhan dien chinh xac hon.
11 skip_frames hoat dong the nao?▼
skip_frames = 2 → chi xu ly AI tren frame chan. Frame le ve lai ket qua cu. Webcam 30 FPS, AI ~15 FPS → ky thuat nay cho hinh muot (30 FPS) ma AI van kip. FPS hien thi van 30, chi co FPS AI la 15.
12 File .pt la gi? Ben trong chua gi?▼
.pt la checkpoint PyTorch. Chua: model_state_dict (trong so model), class_names (ten cac lop), model_name, val_acc (accuracy tot nhat), epoch.
13 Tai sao chi 6 emotion thay vi 8?▼
Model HSEmotion ban dau co 8 class (Anger, Contempt, Disgust, Fear, Happiness, Neutral, Sadness, Surprise). Trong my cho hoc online, Contempt (khinh thuong) va Fear (so hai) rat hiem gap. Bo 2 class nay giup model tap trung vao 6 class con lai, chinh xac hon. Khi dung model goc, code trich xuat 6/8 class bang index [0,2,4,5,6,7].
14 Ki truc tong the cua he thong?▼
He thong nam trong 1 file main.py, gom: (1) EmotionEngine — phat hien mat + nhan dien cam xuc. (2) SessionStats — ghi nhan va bao cao. (3) load_model + do_finetune — fine-tune. (4) do_evaluate — danh gia. (5) 5 mode functions (webcam, image, video, finetune, evaluate). Nguoi dung chon mode qua tham so --mode.
15 Tien trinh xu ly 1 frame nhu the nao?▼
(1) Doc frame tu camera/video. (2) Neu frame chan: eng.process() goi detect → tim mat. (3) Voi moi mat ≥48px: predict() → CLAHE → HSEmotion → 6 xac suat. (4) Temporal Smoothing: lay trung binh 10 frame gan nhat. (5) Adaptive Threshold: so sanh xac suat cao nhat voi nguong rieng → emotion cuoi. (6) Ve bounding box + label len frame. (7) Hien thi. (8) Nhan phim q de thoat.
